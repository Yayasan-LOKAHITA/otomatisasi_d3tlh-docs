# Land Utilization Capability Index (IKP Lahan)

## Overview

This module calculates the **Land Utilization Capability Index (IKP Lahan)**, an indicator used to assess the capability of land resources to support basic human needs, particularly food production and settlement functions, while maintaining ecological sustainability.

The methodology integrates ecosystem service provision, land cover characteristics, forest functions, ecological footprint indicators, and population pressure to estimate land availability and utilization capacity.

The resulting index can be used to evaluate environmental carrying capacity, land-use suitability, and ecological sustainability within D3TLH assessments.

---

## Purpose

To evaluate the capability of land resources in supporting human needs and ecological functions by comparing land availability against land demand.

The analysis produces:

* Land Utilization Capability Index (IKP Lahan)
* Land Availability
* Land Demand
* Land Capability Classification
* Land Capability Score

---

## Required Inputs

### 1. SGSRI Grid Layer

Vector grid dataset representing spatial analysis units.

Required field:

* `ID`

### 2. IJLH Food Provision Layer

Vector dataset representing ecosystem services for food provision.

### 3. Land Cover Layer (PL)

Land cover dataset used to evaluate land utilization and ecological capacity.

Required field:

* `PL`

### 4. Forest Area Layer

Vector dataset containing forest function zoning and protected forest information.

### 5. Population Distribution Grid

Grid-based population distribution dataset.

Required field:

* `POPGRIDYY`

### 6. Food Ecological Footprint (SJEPGN)

Ecological footprint coefficient representing food consumption requirements.

### 7. Built-up Land Ecological Footprint (SJEBUILT)

Ecological footprint coefficient representing settlement and built-up land requirements.

## Output

The algorithm produces:

### 1. Land IKP Grid Layer

Each grid contains:

| Field         | Description                       |
| ------------- | --------------------------------- |
| `ID`          | Grid identifier                   |
| `LAND_AVAIL`  | Available land capacity           |
| `LAND_DEMAND` | Total land demand                 |
| `IKP_LAHAN`   | Land Utilization Capability Index |
| `KELAS_IKP`   | IKP classification                |
| `SKOR_IKP`    | IKP score                         |

### 2. Land Availability Layer

Spatial representation of land resources capable of supporting human needs and ecosystem functions.

---

## Methodology

The Land IKP is calculated by comparing available land resources against land demand generated by population and human activities.

### Food Provision Capacity

The IJLH Food Provision layer is intersected with the analysis grid to estimate ecosystem service capacity for food production.

Output component:

```text
FOOD_SUPPLY
```

---

### Land Cover Assessment

Land cover classes are evaluated to determine their contribution to ecological productivity and land availability.

Output component:

```text
LAND_COVER_SCORE
```

---

### Forest Function Assessment

Forest area functions are incorporated to account for ecological constraints and protected land resources.

Output component:

```text
FOREST_SCORE
```

---

### Population-Based Land Demand

Land demand is estimated using population distribution and ecological footprint coefficients.

Population demand:

```text
LAND_POP
```

---

### Food Demand

Food-related land demand is calculated using:

```text
LAND_FOOD = POPGRIDYY × SJEPGN
```

where:

* `POPGRIDYY` = Population per grid
* `SJEPGN` = Food ecological footprint coefficient

---

### Built-up Land Demand

Settlement and infrastructure demand are calculated using:

```text
LAND_BUILT = POPGRIDYY × SJEBUILT
```

where:

* `SJEBUILT` = Built-up land ecological footprint coefficient

---

### Total Land Demand

Total land demand is calculated as:

```text
LAND_DEMAND = LAND_FOOD + LAND_BUILT
```

---

### Land Availability

Land availability is estimated from:

* Food provision ecosystem services
* Land cover productivity
* Forest area functions
* Ecological suitability

Resulting in:

```text
LAND_AVAIL
```

---

### IKP Lahan Calculation

The Land Utilization Capability Index is calculated as:

```text
IKP_LAHAN = LAND_AVAIL / LAND_DEMAND
```

where:

* `LAND_AVAIL` = Available land resources
* `LAND_DEMAND` = Total land demand

---

### Classification

The resulting IKP values are classified into five categories.

| Score | Class     |
| ----- | --------- |
| 5     | Very High |
| 4     | High      |
| 3     | Moderate  |
| 2     | Low       |
| 1     | Very Low  |

Output fields:

```text
KELAS_IKP
```

```text
SKOR_IKP
```

---

## Processing Workflow

1. Harmonize the coordinate reference system (CRS) of all input datasets.
2. Repair invalid geometries and create spatial indexes.
3. Load:

   * SGSRI Grid
   * IJLH Food Provision
   * Land Cover
   * Forest Area
   * Population Distribution Grid
4. Standardize input fields.
5. Calculate food provision capacity.
6. Evaluate land cover productivity.
7. Evaluate forest area functions.
8. Calculate food-related land demand using:

   * `SJEPGN`
9. Calculate built-up land demand using:

   * `SJEBUILT`
10. Calculate:

    * `LAND_DEMAND`
11. Estimate:

    * `LAND_AVAIL`
12. Calculate:

    * `IKP_LAHAN`
13. Classify IKP values into:

    * Very High
    * High
    * Moderate
    * Low
    * Very Low
14. Assign:

    * `KELAS_IKP`
    * `SKOR_IKP`
15. Generate the final Land IKP layer.
16. Generate the Land Availability output.

---

## Output Interpretation

### High IKP Values

Indicate:

* Land resources exceed demand
* Strong ecological carrying capacity
* Sustainable land utilization
* Lower environmental pressure

### Moderate IKP Values

Indicate:

* Land demand and supply are relatively balanced
* Moderate ecological pressure
* Continued monitoring is recommended

### Low IKP Values

Indicate:

* Land demand exceeds available resources
* High environmental pressure
* Potential ecological deficit
* Increased land-use conflicts

### High SKOR_IKP

Indicates areas with strong land support capacity and sustainable utilization potential.

### Low SKOR_IKP

Indicates areas requiring improved land management and ecological restoration.

* D3TLH analysis workflows

---

## Notes

* All input datasets should use the same CRS.
* Population and ecological footprint values should represent the same analysis year.
* Land cover quality significantly affects the resulting land availability estimates.
* Forest area functions are incorporated as ecological constraints.
* The quality of the index depends on the accuracy of ecosystem service, population, and land cover datasets.
